The interface, drawn with the same pencil

These are not CSS. They are transparent PNGs rendered by scripts/paint/sketches/chrome.js through the same pipeline as the plates, so they carry real graphite texture and a baseline that wanders the way a hand does. That is the difference between an interface that matches the art and one that was made by it.

divider — replaces hr
underline — replaces button border
corner tick — replaces panel border

What changed, and why

  1. Type warmed to a humanist serif. Inter is a geometric grotesque — precise and cold. A serif sits with warm paper rather than against it. Caveat, which you already load, now carries captions.
  2. Hairline borders gone. A panel reads as a patch of slightly different paper, not as a box.
  3. Corners square, with a drawn tick. 2px radius is neither crisp nor soft. Paper has irregular corners, not round ones — so a registration tick replaces the border where the eye expects one.
  4. The button is an underline. A bordered rectangle is a control; a pencil rule under a word is a note. It thickens on hover instead of filling.
  5. Images sit on the sheet. No frame, a faint shadow, so a plate reads as laid on the page.
  6. Rules are drawn. The divider is graphite with a wandering baseline.

To try it live

public/soft.css is a complete drop-in layer. Add <link rel="stylesheet" href="/soft.css" /> to index.html after the app styles, or move it into src/ and import it from main.jsx to get it bundled. Nothing in src/ has been modified.

One caveat worth knowing before flipping it on: the layer uses * { border-radius: 0 !important }, which is deliberately blunt for a demo but too broad for production — it will flatten avatars and any pill-shaped control. The real version should target the specific components instead.
